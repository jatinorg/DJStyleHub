# DJ Style Hub ✨

An exclusive e-commerce showcase studio for **Women's and Kids' unstitched dress materials**, built with React, Vite, TypeScript, and Tailwind CSS.

---

## 🌟 Key Features

- **Exclusively for Women & Kids**:
  - **Women's Collection**: Handblock Jaipur pure mulmul cotton, royal Chanderi silk with zari weaving, Lucknowi Chikankari georgette, and Banarasi brocade.
  - **Kids' Collection**: Boys festive jacquard kurta-pyjama fabrics, girls brocade lehenga-choli materials with soft skin barrier lining, and breathable organic cottons.
- **Exact Yardage Specifications**: Every item displays transparent cut lengths (Top: 2.50m, Bottom: 2.00–2.25m, Dupatta: 2.25–2.40m).
- **Instant WhatsApp Ordering & Payout**:
  - Direct one-click **"Order on WhatsApp"** button on every product with pre-filled SKU, fabric, price, and color.
  - Shopping bag checkout via WhatsApp with automatic item summary, coupons, and subtotal calculation.
- **Interactive Tailoring Guide**: Yardage breakdown, kids' comfort standards, and wash & care recommendations.
- **Responsive & Minimalist Design**: Modern, fast, and mobile-optimized boutique UI.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Running Locally

```bash
# Clone the repository
git clone <your-repo-url>
cd djstyle-hub

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Building for Production

```bash
npm run build
```
Production assets are generated in the `dist/` directory.
